# Phase 1 ビューア

## 目的

Phase 0で変換したレシピを使い、次のループを確認する。

```text
材料または料理名で探す
  → カテゴリ・主要材料で絞る
  → レシピを選ぶ
  → 人数を変更する
  → 材料と手順を見ながら料理する
```

## 起動

Phase 0のJSONからビューア用データを生成する。

```bash
python3 tools/build_viewer_data.py
```

静的HTTPサーバーを起動する。

```bash
python3 -m http.server 8000 --directory web
```

ブラウザで [http://localhost:8000](http://localhost:8000) を開く。

## 現在の機能

- 料理名・読み・材料名・別名・タグ検索
- カテゴリ絞り込み
- 主要材料絞り込み
- 検索結果の順位付け
  - タイトル：高い
  - 主要材料：高い
  - カテゴリ・全材料：通常
- 人数変更と分量換算
- スマートフォン向けの人数ステッパー（−／＋）
- 元レシピの人数へ戻す「標準に戻す」操作
- 主要材料の表記ゆれをまとめた絞り込み（なす／茄子など）
- 手順内の分量を元の文章のまま表示
- 要確認フラグの表示
- 元URLへのリンク
- スマートフォン向けレイアウト

## Phase 1で確認すること

- 「豚肉」で探したとき、豚肉メインのレシピが上位に出るか
- 「なす」「ナス」「茄子」が同じように見つかるか
- 主菜・副菜などの絞り込みが自然か
- 2人分から4人分にしたとき、材料表示が実用的か
- 数値で換算できない分量が、壊れず原文で表示されるか
- スマートフォンで手順を追いやすいか

## 制限事項

- 現在は静的JSONを読み込むだけで、編集・登録はない
- 人数換算は数値・分数・範囲の簡易対応
- 手順内の分量はまだ材料欄と連動しない
- Phase 0のJSONを更新したら `build_viewer_data.py` を再実行する
