# 開発ロードマップ

MVPまでの検証経緯は[history](history/README.md)に保存し、この文書では今後の開発だけを管理する。

## 現在地

MVPの主要機能は実装済み。

- レシピサイトURL・ファイルからのJSON生成
- 生成結果の確認・修正・保存
- タイトル、カテゴリ、主要材料による検索
- 人数変更と材料分量の換算
- スマートフォン向けビューア
- Cloudflare Workers + R2への移行
- フロントエンド・Workerの自動テスト

現在は、個人利用の公開環境を整備する段階にある。

## 次に行うこと

### 1. 継続デプロイと試験公開

- 非公開GitHub Repositoryを作る
- mainへのpush時に自動テストする
- テスト成功後にCloudflareへ自動デプロイする
- Cloudflare Accessで本人だけに公開する
- 最初は`workers.dev` URLを使用する

### 2. 日常利用での検証

- 複数端末から登録・閲覧する
- URL変換の失敗例を集める
- 編集しづらい項目を確認する
- R2保存と履歴からの復旧を確認する
- 実際の料理中に表示を評価する

### 3. 既存レシピの移行

現在保存している約190件を段階的に移行する。

1. 20〜30件を変換する
2. スキーマとプロンプトを調整する
3. 残りを一括変換する
4. 要確認レシピだけを手動で修正する

### 4. 実利用後の改善候補

- 手順内分量の人数連動
- レシピ編集・削除
- 保存履歴からの復元
- 元ソースからの再変換と差分確認
- オフライン対応の強化
- YouTube概要欄・字幕の取り込み

## DBへ移行する判断基準

次のいずれかが必要になった時点で、R2の単一一覧JSONからD1などへの移行を検討する。

- 複数ユーザー
- 同時更新
- レシピごとの権限
- 大量データに対する複雑な検索
- 一覧JSON全体を書き換える方式が性能上の問題になる
