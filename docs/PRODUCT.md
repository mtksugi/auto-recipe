# プロダクト方針

## 目的

auto-recipeは、実際に作って気に入った料理だけを保存する、自分専用のレシピ集である。

新しい料理を探すサービスではない。Webなどで見つけて一度作り、また作りたいと思ったレシピを「殿堂入り」させるために使う。

## 中心となる利用場面

```text
手元の材料や料理名から探す
  → 今日作るレシピを選ぶ
  → 人数を指定する
  → 換算済みの材料と手順を見ながら料理する
```

登録は次の流れとする。

```text
URLまたはファイルを入力
  → レシピ候補を自動生成
  → 人が確認・修正
  → 確定版として保存
```

## 設計原則

### 確定版を保存する

閲覧するたびにAIで再生成せず、登録時に確認したJSONを表示する。表示が速く、過去の手修正が失われないことを優先する。

### 元ソースを追跡できるようにする

元URL、サイト名、変換バージョンなどを残す。将来スキーマやプロンプトを更新した場合も、現在の確定版を無条件で上書きしない。

### 料理中の使いやすさを優先する

- スマートフォンで読みやすい
- 材料と分量をすぐ確認できる
- 人数変更を元の人数へ戻せる
- 手順が適切な単位に分かれている
- 表記ゆれがあっても主要材料から探せる

### AIの完全自動化を目的にしない

変換精度を100%にするより、実用的な候補を作り、人が短時間で確認・修正できることを重視する。

## 現在の対象範囲

- 本人利用
- レシピサイトURL
- PDF、画像、テキストファイル
- レシピの確認、修正、保存、検索、人数換算
- 複数端末からのWeb利用

## 当面の対象外

- レシピを探すための推薦サービス
- 複数ユーザー間の共有や権限管理
- 同時編集
- YouTube動画だけを根拠にした完全な手順生成
- ネイティブアプリ

対象外の機能は、実利用で必要性が確認できてから追加する。
